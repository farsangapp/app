Voice is on by default, and each alert type can be switched off on the iPhone. Speech plays through Bluetooth headphones, and Mute on the Controls screen silences it. Whether the watch speaker can speak aloud with no headphones is something the first real-watch test has to confirm.

Not in this first rollout: Metrics 2, Split, Elevation, Power and Activity Rings (all Apple views), plus our own screens like Route progress. Turn cues and off-route warnings still pop up over whichever page you're on, as in the last sketch. About Lock: Apple's current controls list doesn't include it. Users report Water Lock moved to the system Control Center in watchOS 10, so I left it out.
